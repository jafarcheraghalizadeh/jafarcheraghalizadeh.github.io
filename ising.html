RELAXATION TOWARD EQUILIBRIUM

Energy versus Monte Carlo sweeps

Choose Random reset, then Start to follow relaxation from a disordered configuration. At fixed temperature, the energy typically approaches a fluctuating steady level. Energy need not decrease at every sweep, and a plateau alone does not prove equilibration, especially near the critical temperature.

Changing temperature keeps the current configuration, sweep count, and energy history. Dashed gold lines mark temperature changes. Random reset or Align all spins starts a new trace with a new configuration.

What should you look for?

01 / COOL

Aligned domains

Try T = 1.00 and start from random spins. Regions of the same color tend to grow. Relaxation can be slow, so let the model run.

02 / EXPLORE

Near the transition

Try T ≈ 2.27. The infinite square lattice at zero field has a critical temperature Tc = 2/ln(1 + √2) ≈ 2.269. This finite grid shows a rounded transition and slow relaxation.

03 / HEAT

Thermal disorder

Try T = 4.00. Spins fluctuate more freely, and magnetization usually stays near zero after equilibration.

How the model works

Each site has a spin s = +1 or −1. The energy is H = −J Σ⟨i,j⟩ sisj, where each nearest-neighbor pair is counted once. Matching neighbors lower the energy. The grid wraps at its edges, so every spin has four neighbors.

To attempt an update, choose a random spin and calculate ΔE = 2J si Σneighbors sj. Accept the flip when ΔE ≤ 0. Otherwise, accept it with probability exp(−ΔE/T) in the reduced units used here. Repeating this Metropolis rule samples thermal configurations after equilibration.

Magnetization per spin is m = Σsi/N. Values near +1 or −1 indicate alignment; values near zero can indicate disorder or a mixture of oppositely aligned domains.

Learn by coding

Show the Metropolis update
// J = 1; T is in units of J / kB.
// neighbors(i) returns the sum of four adjacent spins.
const i = Math.floor(Math.random() * spins.length);
const deltaE = 2 * spins[i] * neighbors(i);

if (deltaE <= 0 ||
    Math.random() < Math.exp(-deltaE / temperature)) {
  spins[i] *= -1;
}

Try these exercises

  1. Change the lattice size and compare the behavior near the transition.
  2. Add a magnetic field h: include 2hsi in the spin-flip energy change and −hΣsi in the total energy.
  3. Record magnetization after equilibration and plot its average absolute value against temperature. Repeat with independent runs to estimate uncertainty.
