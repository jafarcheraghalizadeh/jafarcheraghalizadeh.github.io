Why does this matter?

At each step, the walker chooses left, right, up, or down with equal probability. Steps are independent. This simple model helps explain diffusion, stochastic motion, and polymer chain configurations.

For many independent walks of N unit steps, the average squared distance is ⟨r²⟩ = N. The root-mean-square distance is therefore √N. A single trajectory fluctuates and need not match this average; it can also return toward its starting point.

Try an experiment

  1. Pause after 100 steps and note r².
  2. Reset and repeat several times. Compare the average of r² with 100.
  3. Repeat at 400 steps. The predicted RMS distance doubles, from 10 to 20.

Code a walk in Python

import random

x, y = 0, 0
directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]

for step in range(1000):
    dx, dy = random.choice(directions)
    x += dx
    y += dy

print("Position:", x, y)
print("Squared distance:", x*x + y*y)
