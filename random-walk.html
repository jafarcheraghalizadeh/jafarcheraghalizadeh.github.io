Erased-loop statistics

Loop length counts edges, including the step that closes the loop. A step followed immediately by its reversal forms a length-2 loop. Statistics count chronological erasure events in this run, rather than all possible loops in the original trajectory.

How chronological loop erasure works

The underlying walker chooses one of four neighboring lattice sites with equal probability. If it reaches a site already on the retained path, the part after that site is removed. The new closing step is also erased. The surviving path therefore never visits a site twice.

The bookkeeping identity is: total random-walk steps = retained edges + total erased edges. The walker’s position follows the ordinary random walk; loop erasure changes the stored path, not the motion.

Loops that revisit sites already erased from the retained path do not trigger an erasure unless that site is currently present. The plot describes this finite run; it is not an equilibrium distribution or an average over independent runs.

Try an experiment

  1. Use One step to catch short backtracking loops.
  2. Let the simulation run and compare length-2 events with longer loops.
  3. Reset and repeat at the same step count. Compare retained length and erased-loop statistics across runs.

Code loop erasure in Python

import random

path = [(0, 0)]
indices = {(0, 0): 0}
loop_lengths = []
x = y = 0

for _ in range(1000):
    dx, dy = random.choice([(1, 0), (-1, 0), (0, 1), (0, -1)])
    x, y = x + dx, y + dy
    site = (x, y)
    if site in indices:
        k = indices[site]
        loop_lengths.append(len(path) - k)
        for removed in path[k + 1:]:
            del indices[removed]
        del path[k + 1:]
    else:
        indices[site] = len(path)
        path.append(site)

print("Retained edges:", len(path) - 1)
print("Erased loops:", len(loop_lengths))
print("Erased edges:", sum(loop_lengths))
