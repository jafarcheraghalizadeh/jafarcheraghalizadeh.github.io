Growth statistics

Each point records one completed layer. W = √⟨(h − ⟨h⟩)²⟩ measures the spread of heights across all L sites. Mean height uses linear axes; roughness uses log–log axes. Zero time and zero roughness are omitted from the logarithmic plot.

Surface roughness

The power-law estimate appears after five positive measurements.

The orange curve estimates W ≈ A tβ by ordinary least squares of ln W against ln t over all positive measurements in this run. All measured points use the same hollow circle marker. A fitted exponent over the full run can mix early growth and saturation; it is not a reliable universal growth exponent.

These are measurements of a single stochastic run. They do not establish scaling exponents. For random deposition, the square root of the ensemble mean of W² is √[t(1 − 1/L)].

Three ways to grow

Random deposition: choose a site uniformly and increase its height by one. Each deposition event chooses a column uniformly.

Deposition with relaxation: choose a site and deposit on the lowest site among it and its two nearest neighbors, choosing uniformly among ties. Local relaxation smooths the surface.

Ballistic deposition: at the chosen site i, set hᵢ to max(hᵢ + 1, h of each of its two neighbors). A falling particle sticks on first vertical or lateral contact. This height-envelope model includes voids, so mean height can exceed the number of deposited layers.

Try an experiment

  1. Run random deposition for 100 layers and compare W with √t.
  2. Reset with relaxation and the same substrate length. Compare roughness at the same layer count.
  3. Try ballistic deposition. Why can mean height grow faster than one height unit per layer?
  4. Repeat each run to see how random fluctuations change the results.

Code random deposition in Python

import numpy as np

rng = np.random.default_rng(42)
L = 32
h = np.zeros(L, dtype=int)
for t in range(1, 101):
    for _ in range(L):
        x = rng.integers(L)
        h[x] += 1
    mean_height = h.mean()
    roughness = h.std()
    print(t, mean_height, roughness)

Practice: calculate surface roughness

A four-site surface has heights 0, 1, 1, and 2. Calculate its mean height and roughness.

Show the worked answer

Mean height is (0 + 1 + 1 + 2)/4 = 1. The mean squared deviation is (1 + 0 + 0 + 1)/4 = 0.5, so W = √0.5 ≈ 0.707 height units.
